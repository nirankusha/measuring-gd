# Measuring Gradual Disempowerment

**From Economic Primitives to Human Economic Power** — project page for the working paper by Pawel Oczkowski.

- Website: https://nirankusha.github.io/measuring-gd/
- Paper (PDF): [`docs/paper.pdf`](docs/paper.pdf)

This repository holds only the public project page (`docs/`), served with GitHub Pages.
The simulation notebook, analysis code, LaTeX source and derived data are in a private
repository; access for viewing or cloning is granted on request through the
[access request form](../../issues/new?template=code-access.yml).
