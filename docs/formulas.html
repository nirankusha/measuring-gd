Formulas & provenance

Where each quantity in the pipeline comes from

The paper has two versions, and each was produced by its own notebook: the v2.1 design-intent run (Grad_Dis_Simulation_v2_1.ipynb) and the illustrative run (Grad_Dis_Simulation_8-6_original.ipynb). Every formula below was checked against the code of the version it belongs to. Cards tagged differs between versions show what that version actually computes. Cards tagged paper text differs mark places where the paper's wording does not yet match the code.

Version

Provenance classes

  • Data Read directly from Anthropic Economic Index (AEI) releases.
  • Data + transformation Computed from AEI data by a documented step (aggregation, renormalisation, interpolation).
  • External Taken from outside the AEI: METR time horizons and the national aggregates the model presupposes.
  • GD model A modelling choice of this paper: functional forms and fixed coefficients that are set by the author, not estimated.
  • Fitted Estimated from the sector–release observations.

1 · AEI measurement layer

Three sectors: Computer & Mathematical, Legal, Retail. Index \(s\) is the sector, \(t\) the release.

Penetration \(p_{s,t}\)differs between versionspaper text differsData + transformation

\[ p_{s,t}=\frac{\sum_{i\in s} n_{i,t}/k_i}{\sum_{i} n_{i,t}}\,,\qquad i=\text{classified O*NET task},\ k_i=\#\text{occupations sharing task } i \]

The share of classified Claude.ai conversations whose task maps to SOC group \(s\): 15-xxxx, 23-xxxx, or 41-2xxx (Retail Sales Workers). A task shared by \(k\) occupations counts \(1/k\) toward each. There are five releases, each read from its own files, with no interpolation.

Appendix B.1 of Paper A still prints \(p_s=\tfrac1{N_s}\sum_{i\in s}pct_i\), which is the illustrative form.

Audit check: Feb 2025 C&M share within 1 pp of the AEI-reported 37.2%. Usage shares sum to 100% across occupations, so they measure composition, not economy-wide adoption.

Penetration \(p_{s,t}\)differs between versionsData + transformation

\[ p^{obs}_{s,t}=\operatorname{clip}\Bigl(\tfrac{1}{N_s}\textstyle\sum_{i\in s}pct_{i,t},\ 0.01,\ 0.85\Bigr)\quad(2025),\qquad p^{obs}_{s,2026}=0.55\,\frac{\log(1+\overline{raw}_s)}{\log 101}\quad(\text{API proxy}) \] \[ p_{s,t}=\exp\bigl(a_s+b_s\,t\bigr)\quad\text{through the two anchors } p^{obs}_{s,\text{Feb 2025}},\ p^{obs}_{s,\text{Mar 2026}} \]

Sector rows are found by keyword (“computer”, “mathematical”, “legal”, “retail”). There are four releases (Feb 2025, Mar 2025, Sep 2025, Mar 2026). The Mar 2026 value is a compressed raw-API activity proxy, not task penetration. A log-linear path between the two anchors replaces every value. Paper B notes that this makes the run an illustration of the pipeline: rebuilt from a single measure, penetration is roughly constant.

Interaction weights \(w_j\)differs between versionspaper text differsData

\[ w_{j,t}=\frac{pct_{j,t}}{\sum_{k\in\mathcal{J}}pct_{k,t}},\qquad \mathcal{J}=\{\text{directive},\ \text{feedback loop},\ \text{task iteration},\ \text{learning},\ \text{validation}\} \]

The five documented AEI categories, renormalised after excluding none and not_classified. Weights are release-level. Appendix B.1 does not state the exclusion.

Interaction weights \(w_j\)differs between versionsData + transformation

\[ w_{j,t}=\frac{\sum_{c\to j}pct_{c,t}}{\sum_{c}pct_{c,t}} \]

Categories are mapped to channels by keyword match. Any category that matches none of the five keywords is assigned to \(w_{iter}\), and that includes none and not_classified. Fixed default weights apply if a release has no interaction file.

2 · Autonomy and complexity

Autonomy \(A_u\)differs between versionsData

\[ A_{u,t}=w_{dir,t}+w_{feed,t}\qquad\bigl(\text{robustness: }A_u=0.10+0.70(1-e^{-1.8p})\bigr) \]

The main specification is the AEI automation share (directive plus feedback loop). It is release-level. The smooth function is kept as a robustness check (AUTONOMY_SPEC='smooth_p').

Autonomy \(A_u\)differs between versionsGD model

\[ A_u=0.10+0.70\bigl(1-e^{-1.8p}\bigr) \]

A smooth saturating function of penetration, so it varies by sector and release only through \(p\).

Base empirical complexity \(C_{base}\)GD model

\[ C_{base}=1+0.30\,p+0.25\,w_{iter}+0.20\,w_{feed}+0.15\,w_{valid} \]

The inputs are AEI data. The linear form and the coefficients are fixed, not estimated.

Frontier ratio, pressure and accessibilityGD model

\[ R_f=\frac{C_{base}}{Q_{0.50}(C_{base})},\qquad P_f=R_f^{2},\qquad F_A=\frac{1}{1+\exp\!\bigl(4\,(P_f-1)\bigr)} \]

\(Q_{0.50}\) is the median over all sector–release observations, so the frontier is a fixed benchmark relative to the sample. METR does not enter \(F_A\).

Empirical and cognitive complexitypaper text differsGD model

\[ C_{emp}=C_{base}+0.10\,P_f,\qquad C_{cog}=C_{emp}\bigl(1+(1-F_A)\bigr)=C_{emp}\,(2-F_A) \]

The appendix of both papers (B.2) writes \(C_{emp}\) with a term \(\alpha_5R_f\), linear in \(R_f\). The code adds \(0.10\,R_f^2\).

4 · Capital and labour construction

Presupposed national aggregatesExternal

\[ Y_s=\mathrm{GDP}\cdot g_s,\qquad H^{total}_s=H_{macro}\,\frac{g_s}{\sum_s g_s},\qquad K_s=K_{macro}\,\frac{Y_s}{\sum_s Y_s} \]

\(\mathrm{GDP}=27.5\) trillion USD, \(K_{macro}=75\) trillion USD, \(H_{macro}=3.3\times10^{11}\) hours. The GDP shares \(g_s\) are 0.060 for C&M, 0.015 for Legal and 0.062 for Retail. These values are assumed, not observed by the AEI. Because \(K\propto Y\), the production elasticities in layer 5 are not identified.

Displaced share and effective human labourGD model

\[ \omega_{s,t}=\operatorname{clip}\bigl(p_{s,t}A_{u,s,t},\,0.001,\,0.95\bigr),\qquad H_{s,t}=H^{total}_s\,(1-\omega_{s,t}) \]

AI capital and gated AI capitalGD model

\[ K_{AI,s,t}=H_{s,t}\,p_{s,t}\,C_{cog,s,t},\qquad K^{eff}_{AI,s,t}=K_{AI,s,t}\,F_{A,s,t} \]

Measured in labour-equivalent units. \(F_A\) is the accessibility gate.

Verification capitalpaper text differsGD model

\[ v_{s,t}=p_{s,t}\,(w_{feed}+w_{valid})\,\bigl(1+(1-F_A)\bigr),\qquad s_{ver}=0.02+0.35\bigl(1-e^{-3v}\bigr) \] \[ K_{ver}=K\,s_{ver},\qquad K_{ord}=K\,(1-s_{ver}) \]

The appendix of both papers (B.5) prints the amplifier as \(1+P_f\). Both notebooks use \(1+(1-F_A)\).

\[ AI^{global}_{s,t}=H^{total}_s\,p_{s,t} \]

5 · Production fits

OLS in per-hour form with constant returns imposed. \(\beta\) is not estimated; it is backed out as \(1-\sum\)(other elasticities).

V1 baselineFitted

\[ \ln\frac{Y}{H}=\ln A+\alpha\ln\frac{K}{H}+\gamma\ln\frac{AI^{global}}{H},\qquad \beta=1-\alpha-\gamma \]

V2 explicit AI capitalFitted

\[ \ln\frac{Y}{H}=\ln A+\alpha_{ord}\ln\frac{K_{ord}}{H}+\alpha_{AI}\ln\frac{K_{AI}}{H},\qquad \beta=1-\alpha_{ord}-\alpha_{AI} \]

V3 gated AIFitted

\[ \ln\frac{Y}{H}=\ln A+\alpha_{ord}\ln\frac{K_{ord}}{H}+\alpha^{eff}_{AI}\ln\frac{K^{eff}_{AI}}{H},\qquad \beta=1-\alpha_{ord}-\alpha^{eff}_{AI} \]

\(\alpha_{ord}\gt1\) and \(\beta\lt0\) in both runs (v2.1 main: \(\alpha_{ord}\approx1.08\)–\(1.13\), \(\alpha^{eff}_{AI}\approx0.023\)). The negative \(\beta\) absorbs the excess created by imposing constant returns while \(K\propto Y\). It is not labour's elasticity. It affects only layer 6, not the HEP results.

6 · Five-channel layer (illustration)

The same code in both versions. It inherits \(\beta\) from layer 5, so its outputs are illustration, not measurement.

Structural channel elasticitiesGD model

\[ \gamma_j=\alpha_{AI}\,w_j,\qquad j\in\{dir,\,feed,\,iter,\,learn,\,valid\} \]

Activation targetsGD model

\[ a^{*}_{auto}=p\,A_u,\qquad a^{*}_{aug}=p\,(1-A_u),\qquad a^{*}_{ver}=\tilde C\,A_u\,p\,(1-F_A) \]

\(\tilde C\) is min–max normalised \(C_{emp}\).

Activation modelFitted

\[ \operatorname{logit}\,a^{*}_m=b_0+b_1\tilde C+b_2A_u+b_3p,\qquad a_m=\operatorname{logit}^{-1}\bigl(\hat b^\top x\bigr) \]

One small OLS-logit per mechanism. It is a structural diagnostic, not inference.

Effective elasticities and channel inputsGD model

\[ \gamma^{eff}_{dir,feed}=\gamma_{dir,feed}\,a_{auto},\quad \gamma^{eff}_{iter,learn}=\gamma_{iter,learn}\,a_{aug},\quad \gamma^{eff}_{valid}=\gamma_{valid}\,a_{ver} \] \[ AI_{j,s,t}=H^{total}_s\,p_{s,t}\,w_{j,t} \]

Five-channel output and compute shockGD model

\[ Y=A\,K_{ord}^{\alpha_{ord}}\,H^{\beta}\prod_{j}AI_j^{\gamma^{eff}_j} \]

The compute shock multiplies \(AI_{dir}\) and \(AI_{feed}\) by 5.

Verification share from \(\gamma_5\) (diagnostic)GD model

\[ s_{ver,\gamma}=\frac{1}{1+\exp\!\bigl(-(2500\,\gamma^{eff}_{valid}-1.5)\bigr)},\qquad K^{diag}_{ver}=K\,s_{ver,\gamma} \]

Not used as a regressor.

7 · Human Economic Power

Effective AI participation \(L\)differs between versionsData + transformation

\[ L^{emp}_{s,t}=p_{s,t}\,(w_{dir,t}+w_{feed,t})\qquad\bigl(\text{sensitivity: }L=p\,A_u\,C_{AI}\bigr) \]

Under the main specification both factors are AEI data.

Effective AI participation \(L\)differs between versionsGD model

\[ L^{emp}_{s,t}=p_{s,t}\,A_u(p_{s,t})=p\,\bigl[0.10+0.70(1-e^{-1.8p})\bigr] \]

Paper B's conceptual definition is \(L=P\,A_u\,C_{AI}\), and Section 3 explains that \(C_{AI}\) is represented through the complexity measures. In code, frontier capability enters \(K_{AI}\) through \(C_{cog}\), not \(L\).

Empirical HEPGD model

\[ P^{emp}_{H,s,t}=\frac{H_{s,t}}{H_{s,t}+K^{eff}_{AI,s,t}} \]

A structural power proxy, not a literal income share. The conceptual \(HEP=e\cdot\omega_L\) in Section 2 is a different, unmeasured quantity.

Theoretical HEP curveGD model

\[ P_H(L;\lambda)=\frac{e^{-\lambda L}(1-L)}{e^{-\lambda L}(1-L)+\bigl(1-e^{-\lambda L}\bigr)L} \]

Displacement steepness \(\hat\lambda\)differs between versionsFitted

\[ \hat\lambda=\arg\min_{\lambda}\frac{1}{N}\sum_{s,t}\Bigl(P^{emp}_{H,s,t}-P_H\bigl(L^{emp}_{s,t};\lambda\bigr)\Bigr)^2 \]
Run (15 obs.)\(\hat\lambda\)MSE

Robustness, smooth \(A_u\)5.01—

The observed \(L\) stays below about 0.2, where \(\lambda\) is weakly identified. The paper reports this as a null result, not a measured displacement rate.

Displacement steepness \(\hat\lambda\)differs between versionsFitted

\[ \hat\lambda=\arg\min_{\lambda}\frac{1}{N}\sum_{s,t}\Bigl(P^{emp}_{H,s,t}-P_H\bigl(L^{emp}_{s,t};\lambda\bigr)\Bigr)^2=1.5705 \]

Fitted on 12 observations, with mean squared error 3.64e−3. This is the value the illustrative paper uses (\(\hat\lambda\approx1.57\)). It depends on the interpolated penetration path in layer 1.

8 · Attractor diagnostics

The same rules in both versions. With 12–15 points and all thresholds at zero, the labels are descriptive tags, not findings.

Mahalanobis distance to the HEP curvepaper text differsGD model

\[ D_{M,s,t}=\min_{L'}\sqrt{\bigl(z_{s,t}-z^{*}(L')\bigr)^{\!\top}\Sigma^{-1}\bigl(z_{s,t}-z^{*}(L')\bigr)},\qquad z=(L^{emp},P^{emp}_H),\ z^{*}(L')=\bigl(L',P_H(L';\hat\lambda)\bigr) \] \[ v_{D,s,t}=D_{M,s,t}-D_{M,s,t-1},\qquad a_{D,s,t}=v_{D,s,t}-v_{D,s,t-1} \]

\(\Sigma\) comes from the Feb and Mar 2025 releases, with ridge \(10^{-5}I\), on a 1,000-point curve grid. Appendix B.7 of both papers prints \(D_M\) without the square root.

Mechanism distances and basin radiusGD model

\[ D_{M,m}=\sqrt{(x_m-\mu_m)^{\top}\Sigma_m^{-1}(x_m-\mu_m)},\qquad r_m=Q_{0.95}\bigl(D_{M,m}\ \text{over the baseline}\bigr) \]

Coordinates \(x_m\): automation \((\ln K_{ord},\ln K^{eff}_{AI})\), augmentation \((\ln H,\ln K^{eff}_{AI})\), verification \((\ln K^{eff}_{AI},\ln K_{ver})\). The baseline is all releases of the run, with ridge \(10^{-5}\).

Evidence scoreGD model

\[ E_m=0.5\,I_r+1.0\,I_D+1.5\,I_v+2.0\,I_a \]

\(I_r=\mathbb 1[\varepsilon_m\gt0]\), \(I_D=\mathbb 1[D_{M,m}\gt r_m]\), \(I_v=\mathbb 1[v_m\gt0]\), \(I_a=\mathbb 1[a_m\gt0]\), where \(\varepsilon_m\) is the mechanism's log-output residual. Labels: \(E\lt1\) smooth substitution; \(1\le E\lt2.5\) weak deviation; \(2.5\le E\lt4\) manifold drift; \(E\ge4\) phase-shift candidate. The weights are heuristic.
